# 津门小桌 · 天津麻将

面向两位家人的轻量网页麻将：两人跨网络同桌，两个电脑补位；单人试玩时由三个电脑陪打。规则基于维基百科《天津麻将》，具体变体与歧义取舍见 [规则说明](docs/RULES.md)。

## 运行

需要 Node.js 22 或以上。

```sh
npm ci
npm start
```

打开 http://localhost:3000 ，填写称呼并开桌。另一位在独立浏览器或手机输入房间号，加入后再开始。`npm run dev` 可在开发时自动重启服务。

## 本机共享

macOS 安装 `cloudflared` 后，停止单独运行的开发服务，再执行：

```sh
npm run share:start
npm run share:status
```

使用输出的 HTTPS 地址联机。共享由后台进程管理，停止命令为 `npm run share:stop`。电脑需保持联网；临时地址在隧道重建后会改变。详见 [运行与部署](docs/DEPLOYMENT.md)。

## 当前实现

- 136 张牌、双混儿、碰杠、自摸、特色胡牌与组合计分、坐庄拉庄、连庄。
- 六位房间号与邀请链接，固定真人对坐，服务端裁定和私有手牌视图。
- 策略电脑玩家、主动托管、自动重连、磁盘保存与进程重启恢复。
- 横屏牌桌、点牌选中、再次点同一张出牌、SVG 牌面与中文标注、四席语音播报（出牌、碰杠胡）、主屏幕应用清单。
- 无注册、无广告、无外部字体或图片请求；仅游戏积分。

支持本机临时隧道共享；真实 iPhone 和国内外网络尚待验收。规则说明列明实体打风流程简化、默认变体和未验证边界。

## 验证

```sh
npm test
npm run check
```

Node 内置测试运行器测试胡牌规则、计分、随机完整对局的牌数与积分守恒，以及双客户端房间授权、隐私、重连与服务重启。集成测试使用临时端口和临时目录，不操作正在试玩的房间。

## 目录

- `src/rules.js`：牌型搜索、计分和人机出牌评分。
- `src/game.js`：纯牌局状态、操作校验、结算和客户端视图。
- `src/server.js`：静态网页、WebSocket、房间凭证、持久化。
- `public/`：无框架前端与响应式牌桌。
- `test/`：规则、牌局与网络集成测试。

语音使用设备自带的中文语音，首次点击“开启语音”激活；每席优先分配不同中文声线，不足时以位置称呼和音高区分。电脑操作至少间隔 3.2 秒，开启语音的在线前台设备完成播报后才继续，最多等待 9 秒。切后台或断线会停止播报，回来后可重新点开启，避免补播过期动作。

只依赖 `ws`；不需要构建前端。服务器保存局面并计算人机行为，手机负责显示和发送操作。

部署方式见 [部署说明](docs/DEPLOYMENT.md)。提供 Docker Compose + Caddy HTTPS 配置，需要有公网服务器和域名后执行。
