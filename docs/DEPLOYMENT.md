# 两地联机部署

## 推荐：AWS Lightsail，新加坡，Linux 1 GB + 公网 IPv4

官方价格表（2026-10-16 查阅）：该档为 **7 美元/月**，2 vCPU、40 GB SSD、2 TB 流量。另计税、域名和可能的超额流量；不把试用优惠计入长期预算。

- [官方价格](https://aws.amazon.com/lightsail/pricing/)
- [可用区域](https://docs.aws.amazon.com/lightsail/latest/userguide/understanding-regions-and-availability-zones-in-amazon-lightsail.html)

选择新加坡是初始部署建议，不是国内访问质量保证。上线前必须让国内家人的实际运营商网络和加拿大网络分别打开测试；若质量不佳，再对比东京或香港，避免先长期付费。游戏所有字体、牌面和代码由同一服务提供，不依赖 Google Fonts 或第三方 CDN。

当前尚未创建云资源、购买服务或公网部署。需要用户的云账号、明确费用授权，以及可用域名。注册、付款和账号验证由用户完成，不要在聊天里发送密码或访问密钥。

## 本地运行

```sh
npm ci
npm start
```

打开 http://localhost:3000 。双人测试请用两个浏览器或两个独立浏览器配置，避免共享座位凭证。一个浏览器可以开局由 3 个电脑陪打；两位真人入座时剩余 2 个电脑陪打。

手机与电脑同一局域网时，可使用电脑局域网 IP 的 3000 端口。跨国使用需要下述公网部署，本地地址不能发给远方家人使用。

## Docker

```sh
docker compose up -d --build game
```

本地仅绑定 127.0.0.1:3000。不向网络公开未加密的座位凭证。

## HTTPS 公网部署

1. 准备运行 Docker Engine 与 Compose 的 Linux 服务器；为实例分配固定公网 IPv4。
2. 域名的 A 记录指向该 IPv4。服务器只对外开放 TCP 80、443；SSH 限制到管理者地址。无需公开 3000。
3. 将本仓库的已验证代码放到服务器上（首次代码提交与推送需另行执行）。
4. 从 `.env.example` 创建 `.env`，设置真实 `DOMAIN`。
5. 执行：

```sh
docker compose --profile public up -d --build
```

Caddy 自动申请和续期 HTTPS 证书并代理 WebSocket。证书签发需要域名解析正确且 80/443 可达。不要用无效证书测试 iPhone。

检查服务：

```sh
docker compose ps
docker compose logs --tail=100 game caddy
```

使用 `https://你的域名/health` 查看健康状态，然后建立房间，让家人输入六位房间号。可用 Safari 的“分享 → 添加到主屏幕”。当前需要联网，没有离线联机能力。

## 存储与维护

- 单实例服务，不可直接横向扩容；内存持有房间状态，磁盘原子写入快照。
- `.data` 或 Docker 的 `game-data` 卷存放牌局、积分和座位凭证。不要公开、提交 Git 或在日志中输出这些文件。
- 服务重启会恢复最近七天内有活动的房间；旧文件目前不会自动物理删除。建议只在备份后人工整理不再使用的房间。
- 不清除浏览器站点数据即可恢复座位；清除后没有账号找回机制。新局开始后不接纳新玩家，防止误接管家人的手牌。
- 暂时离线会保留座位，并等待本人决策；主动点“托管”才会交由电脑代打。
- 更新前备份数据卷。`docker compose down` 保留卷；不要使用 `down -v`，那会删除牌局数据。
- 不要把 `.env`、云密钥或备份文件放进 Git。

## 上线验收

- 两位真人各自加入并在对面，另两席为电脑。
- 验证国内 Wi-Fi、国内移动网络、加拿大网络。
- Safari 横竖屏、主屏幕启动、锁屏 30 秒后返回。
- 出牌后立刻断网再连，确认不会重复出牌；托管开关恢复正常。
- 服务重启后，两部手机恢复同一局与积分。
- 请家人用几组熟悉的胡牌核对分数。模拟浏览器和单元测试不能替代实机验收。
