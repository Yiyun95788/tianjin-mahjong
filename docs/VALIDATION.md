## 浏览器检查

已检查创建房间、开局、坐庄选择、选牌、出牌、电脑应答、托管切换和刷新恢复。横竖屏采用响应式视口检查，窄屏手牌分两行且无水平溢出。语音开关和播报字幕已在浏览器中验证。

## 部署检查

Docker Compose 配置校验通过。容器构建、Caddy 证书签发尚未完成运行验证。

本机共享使用 `share:status` 检查后台进程及本地健康状态。`npm run share:check` 已通过公网 HTTPS 页面、健康检查、两个 WebSocket 客户端加入房间和私有手牌视图检查。该检查不代表国内运营商网络已经验证。
