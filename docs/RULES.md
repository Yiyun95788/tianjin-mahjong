# 天津麻将规则

规则参考[维基百科《天津麻将》](https://zh.wikipedia.org/zh-hans/天津麻将)，2026-10-16 查阅，页面标示版本日期为 2024-09-09。下文记录实现采用的规则及变体。

## 基础牌局

- 136 张，万、筒、条各 36 张，东南西北中发白各 4 张；无花牌。
- 初局随机庄家，真人固定对坐。实体打风、码牌和掷骰动作不播放动画，不模拟每锅重新换座。
- 服务端用加密随机数洗牌并生成三次双骰点数；按前两次点数切墙，四张一轮发三轮，再各发一张，庄家多一张。
- 第三次点数从尾部定位混儿指示牌，保留独立补牌区。指示牌不进入手牌。翻牌与同族下一张均为混儿；九回一、北回东、白回中。
- 不允许打混儿，通过操作校验避免相公；混儿不允许碰杠，也不能代替其他牌碰杠。
- 允许碰、明杠、暗杠、补杠；不允许吃。暗杠牌种公开。碰后出牌，杠后从补牌区尾部摸牌。
- 只能自摸，包括杠开；不允许点炮或抢杠胡。只允许四副一将，无七对、全不靠等特殊结构。
- 常规摸牌区耗尽或补牌区耗尽均荒牌，不跳过指示牌继续补。

## 胡牌判定

引擎搜索不同拆解，取合法最高分。最后摸到的那张单独追踪；捉伍儿和混儿吊不能仅凭整手牌里有该牌型就计分。

| 项目 | 分值与条件 |
| --- | --- |
| 素胡 | 2，手中没有混儿（非混儿按本身使用的变体） |
| 混儿吊 | 2，最后摸牌能与一张混儿组成将 |
| 双混儿吊 | 2，最后摸牌能与两张混儿组成一副 |
| 捉伍儿 | 3，最后摸到伍万或混儿并作为四五六万的中张 |
| 龙 | 4，同花色 123、456、789 三副顺子，可用混儿 |
| 本混儿 | 龙花色与混儿花色相同，在龙的基础上乘 2 |
| 杠开 | 乘 2，胡牌牌张来自杠后补牌 |
| 天和 | 乘 4，庄家起手、尚未出牌且未发生碰杠 |
| 地和 | 乘 4，闲家首次摸牌且此前没有碰杠 |

地和采用未被碰杠打断的首次摸牌约定；百科只简述“抓第一颗牌”，未细化中断条件。天和、地和的倍数在来源中标为有争议，此版本固定为 4。

龙和捉伍儿先相加，其余适用项目相乘，无额外底分。无上述项目的小胡不允许，起胡分为 2（不含杠分）。

来源基本番种一栏对“本混儿龙”的措辞和后续示例容易混淆；这里以组合示例为准：本混儿龙 = 2 × 4 = 8，不再乘一次 4。

组合示例：

- 素捉伍儿 = 2 × 3 = 6。
- 捉伍儿龙 = 3 + 4 = 7。
- 素捉伍儿龙 = 2 × (3 + 4) = 14。
- 本混儿捉伍儿龙 = 2 × (3 + 4) = 14。
- 混儿吊本混儿龙 = 2 × 2 × 4 = 16。
- 双混儿捉伍儿本混儿龙 = 2 × 2 × (3 + 4) = 28。

混儿吊和捉伍儿组合须满足双混儿吊；同时有龙时，双混儿形成的 456 必须位于龙之外。程序分别检验相应剩余牌能否成牌，防止把龙内的 456 重复算作双混儿吊。

## 结算、坐拉庄与连庄

- 明杠、补杠向其余每家收 1 分；暗杠向其余每家收 2 分。开杠立即计入积分，荒牌保留。百科未详列杠分付款方，本版采用三家均付。
- 自摸时三家各支付胡牌基础分，坐拉庄单独作用于每一对付款方与收款方。
- 庄家先选择是否坐庄；不坐则无人拉庄。坐庄后各闲家可选择不拉或拉一庄，不提供拉两庄。
- 坐庄：所有涉及庄家的收付乘 2；该闲家又拉庄则他与庄家的收付再乘 2。此倍数同时应用于杠分。
- 庄家胡牌连庄；闲家胡牌换下家。荒牌时，若庄家无杠且旁家有杠则换庄，否则连庄。
- 不启用“铲”、金杠、“刮大风”及混儿当本牌也算素胡的变体。

## 人机

电脑可见自己的手牌、混儿、各家公开的碰杠和弃牌。不会读取牌墙或其他人的手牌。优先合法胡牌及开杠，出牌按合法胡牌进张、收益和连接结构评分；接近龙时减少碰牌。策略采用启发式评分，不使用训练模型。
